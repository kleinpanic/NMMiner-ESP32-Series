# PanicMiner v4.0.0-rc.1

Open application firmware for the tested ESP32-2432S028R CYD unit, with matching
Mine, Hash, Chain, Clock, Stats, Boot and Setup screens. Source, recovery tools,
tests and NMMiner reverse-engineering notes live in one repository.

## Verified on hardware

- Strict 20-minute Mine test: 1,203.988 seconds, 222 samples, 967.899 kH/s;
  all 17 checks passed, including both rolling rates within 5% of 994 kH/s.
- Same-boot soak: 3,614.418 seconds, 967.925 kH/s, one newly accepted share,
  60 new SD records and 78 complete live-data cycles. No reboot, API gap,
  radio drop, SHA mismatch or uncommanded navigation.
- Full/half-closed SD exports, cancellation, immediate follow-up requests,
  ten blocked-client exports and 66 status requests passed. The post-window
  export returned 409 complete nine-column records.
- JSON and SD source-port reuse after 65 seconds passed, with a bounded close
  for clients waiting for server EOF.
- Five pages, automatic pool recovery after a deliberate Wi-Fi drop, and a
  saved-settings EN reboot with SD mounted passed.

The C++ sanitizer suite and CYD build pass. The Python suite passes 105 tests
and 29 subtests. Original failed attempts and exact measurements are retained
in the [validation record](../panicminer-validation-2026-11-25.md).

## Firmware identity and installation

Tested firmware source: `49afce559587d347bbef0900c66e1e6cf88c8db0`.
Application: 1,781,040 bytes, SHA-256
`23236906a43745274836183fa75348ceca927dee2350919bea08c25ce96de986`.
The release includes the tested application and its matching factory image,
checksums and license notices. Neither contains device settings or a flash backup.

Use the parent README's verified build/flash/restore helpers. Always take and
verify a fresh full 4 MB backup before writing firmware. The observed panel uses
the recorded `ILI9341_2_DRIVER` and inversion configuration; stock identifies it
as ST7789. Other inherited board targets are not hardware-qualified by this run.
Allow about a minute for hashrate windows to fill after boot.

## Remaining acceptance

This is a **release candidate**, not a completed hardware milestone. Charger
cold boot with SD, complete egress capture, portal/fallback-pool persistence
and physical audio/LED checks remain open. The saved-settings reboot used laptop
USB and an EN reset. Do not equate it with a charger power-cycle test.

The miner uses the configured public payout address. Accepted solo shares are
work confirmations, not payments; displayed address funds can include unrelated
transfers. No wallet private key or seed is used. The application source is open;
Espressif radio libraries and chip ROM remain proprietary platform components.
See [firmware provenance](../firmware-provenance.md) for licenses and this boundary.
