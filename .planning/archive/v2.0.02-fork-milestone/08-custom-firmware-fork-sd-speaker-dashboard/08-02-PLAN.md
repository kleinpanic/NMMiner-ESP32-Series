<task type="auto">
  <name>Task 2: Implement speaker.cpp with LEDC driver</name>
  <files>firmware/custom/NerdMiner-CYD-Custom/src/speaker.cpp</files>
  <action>
    Implement the Speaker module using ESP-IDF's LEDC (PWM) driver. The LEDC peripheral is non-blocking by design and allows the mining loop to schedule tones without stalling.

    Implementation steps:
    1. Speaker::init():
       - Configure LEDC timer: LEDC_HIGH_SPEED_MODE, 5 kHz base frequency, 8-bit resolution
       - Configure LEDC channel: GPIO26, LEDC_CHANNEL_1 (separate from backlight LEDC_CHANNEL_0)
       - Default volume: 80% duty cycle

    2. Speaker::playTone(int freq_hz, int duration_ms):
       - Set channel frequency to freq_hz
       - Enable output (duty cycle = volume_percent)
       - Schedule a delayed stop callback (using FreeRTOS timer or millis()-based check in a background task)
       - Return immediately (non-blocking)

    3. Speaker::stop():
       - Set duty cycle to 0 (silence)
       - Disable output

    4. Speaker::setVolume(int percent):
       - Clamp to 0–100
       - Calculate duty from percent (e.g., duty = (percent / 100) * 255 for 8-bit)
       - Apply to LEDC channel

    5. Event helpers (playStartupChime, playShareBeep, playDisconnectAlarm):
       - Call playTone() with preset freq/duration
       - Examples: startupChime = 1000 Hz, 200 ms; shareBeep = 1200 Hz, 100 ms; disconnectAlarm = 800 Hz, 300 ms (repeated)

    Reference: witnessmenow/ESP32-Cheap-Yellow-Display examples for LEDC setup; ESP-IDF LEDC docs.
    Do NOT block the mining thread with delay() inside playTone(). Use FreeRTOS timers or a background task.
  </action>
