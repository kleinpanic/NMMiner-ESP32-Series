# Phase 2 Plan 02: Recover Fonts/Glyphs + Palette Summary

Identified the stock NMMiner v2.0.02 `lv_font_t` descriptors (family + point size +
glyph subset) from their SPEC line-heights, then made matching fonts available to the
fork entirely from OPEN upstreams (D-21): text via LVGL built-in Montserrat (zero added
bytes), icons via a FontAwesome 6 Free subset C-array, plus a corrected bit-replicated
RGB565 color palette header.

## What was built

- **FONT-IDENTIFICATION.md** (gitignored): maps every confirmed descriptor address
  (Loading/Miner/Clock/SPrice/Config) to family + derived point size + glyph subset.
  Size derivation is calibrated against the SPrice explicit px anchors (11/15/23/24/26)
  using the LVGL Montserrat line_height ratio (~lh/1.36), then snapped to built-ins.
  Records open-upstream provenance (FA6 Free TTF path + SHA-256, lv_font_conv version).
- **fa_nmminer_subset.c**: LVGL v8 `lv_font_t` C-array, 16 px / 1 bpp, covering exactly
  `U+F1EB, F019, F57D, F080, F382` (the only `U+Fxxx` codepoints in SPEC). Generated by
  `lv_font_conv@1.5.3` from Font Awesome 6 Free Solid 6.5.1. Build artifact, not closed data.
- **recovered_fonts.h**: declares `extern const lv_font_t fa_nmminer_subset;`, the five FA
  UTF-8 symbol macros (`NMMINER_SYMBOL_WIFI`, etc., verified against the codepoints), and
  documents which point sizes come from LVGL built-in Montserrat (`&lv_font_montserrat_NN`).
- **nmminer_palette.h**: every stock color as `NMMINER_COLOR_*_565` + `_HEX` (bit-replicated),
  grouped by source screen, Clock price-down marked `tentative — confirm in Phase 3`.
- **lv_conf.h**: comment block documenting the resolved Montserrat sizes; all six built-ins
  (12/14/16/22/24/26) were already enabled = zero added repo bytes.

## Resolved font sizes + FA glyphs

- **Montserrat text sizes (all LVGL built-in, zero added bytes):** 12, 14, 16, 22, 24, 26.
  - line_height -> pt: lh16->12, lh18->14, lh21/22->16; SPrice px 23->22, 24->24, 26->26,
    11->12 (snap), 15->14 (snap).
- **FontAwesome subset (one icon font, 16px/1bpp):** U+F1EB (wifi), U+F019 (download),
  U+F57D (globe), U+F080 (chart), U+F382 (bestDiff). Carried by stock descriptors
  0x3f4f1758 and 0x3f467f48.

## D-21 open-upstream confirmation

Every committed font byte traces to an open upstream:
- Text = LVGL built-in Montserrat (Montserrat OFL), generated at compile time from a
  toggle — zero repo bytes.
- Icons = `fa_nmminer_subset.c` generated by `lv_font_conv@1.5.3` from Font Awesome 6
  Free Solid 6.5.1 (`fa-solid-900.ttf`, SIL OFL 1.1, SHA-256
  `fbbf06d7437aa30f3cd44c968380193545a8fc3eadfb7ad897bbb101eefec5a2`).

The closed firmware's `lv_font_t` descriptors were read ONLY to recover family/size/
codepoint identity; no glyph bitmap was copied. The only file referencing descriptor
addresses (FONT-IDENTIFICATION.md) stays gitignored.

## Deviations from Plan

### Auto-fixed / adjusted

**1. [Rule 3 - Blocking] Resolved Montserrat sizes differ from the plan-check hardcoded set**
- **Found during:** Task 2 verify
- **Issue:** The plan-check warning flagged that T2's verify hardcoded 14/16/18/20. The
  actual sizes derived in T1 are 12/14/16/22/24/26 (no 18/20 needed).
- **Fix:** Adjusted the verify to the resolved set; confirmed all six are already enabled
  in lv_conf.h (18/20 also remain enabled, harmless). Documented in FONT-IDENTIFICATION.md.

**2. [Rule 1 - Bug] Corrected bit-replicated #hex vs SPEC bare-shift values**
- **Found during:** Task 3
- **Issue:** SPEC printed some #hex with bare left-shift (oversaturated), e.g. orange
  #EE7D31. D-24 requires bit-replication to agree with the Plan-01 decoder.
- **Fix:** Recomputed every #hex via 5/6/5->8/8/8 bit-replication (orange -> #EF7D31,
  etc.); annotated each diff in nmminer_palette.h.

**3. [Rule 1 - Bug] Badge bg 0x182031 is a 24-bit #hex, not RGB565**
- **Found during:** Task 3
- **Issue:** SPEC lists badge bg as `0x182031` under a 565 column, but 0x182031 exceeds
  16 bits. Reverse-mapping #182031 -> RGB565 = 0x1906.
- **Fix:** Kept #182031 as the HEX, set _565 to the computed 0x1906.

**4. [Rule 2 - Privacy] Stripped absolute home path from generated C-array header**
- **Found during:** Task 2 (pre-commit)
- **Issue:** lv_font_conv embedded `/home/broklein/.local/...` in the Opts comment of the
  committable fa_nmminer_subset.c.
- **Fix:** Replaced the Opts line with a clean provenance block (font name, version,
  SHA-256, tool) — no local absolute path leaked.
