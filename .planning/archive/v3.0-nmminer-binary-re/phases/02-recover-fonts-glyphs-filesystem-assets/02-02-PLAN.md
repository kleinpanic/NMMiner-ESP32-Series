<objective>
Recover ASSET-01: identify the stock fonts from their located `lv_font_t` descriptors (family +
point size + glyph subset) WITHOUT copying closed glyph bitmaps (D-21), make the matching text
fonts available to the fork (prefer enabling LVGL built-in Montserrat where sizes match = zero new
bytes; regenerate from Montserrat OFL otherwise, per D-22), generate a committable FontAwesome
subset font for the Miner-screen glyphs from FontAwesome Free (D-22), and capture the stock color
palette as a committable header with bit-replicated #hex (D-24).

Purpose: Phase 3 rebuilds the screens by `#include`-ing these fonts + palette directly; doing the
recovery here means Phase 3 does no font work. The committed C-arrays are OUR build artifacts
regenerated from open upstreams, never closed-firmware data (load-bearing D-21/D-11 boundary).
Output: A font-identification analysis (gitignored), committable FA subset C-array + fonts header,
a committable palette header, and lv_conf.h built-in enables for the matched Montserrat sizes.
</objective>
