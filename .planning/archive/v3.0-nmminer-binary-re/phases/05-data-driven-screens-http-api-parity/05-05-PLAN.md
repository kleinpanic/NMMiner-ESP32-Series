<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client (LAN) -> apiServer | Untrusted request bodies, query params, and multipart uploads cross into the firmware. |
| apiServer -> NVS / LittleFS | Settings writes and .ss file writes are persistence sinks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-PWD | Info disclosure | /api/setting/{network,mining} GET | mitigate | Never serialize WiFiPWD or pool passwords in GET responses. |
| T-05-SET | Tampering | settings POST handlers | mitigate | Partial-JSON with isNull() skip + type/range validation per field at the boundary (ASVS V5). |
| T-05-UPL | Tampering/DoS | /api/update/screensaver | mitigate | Validate magic 0x53 0x4E in UPLOAD_FILE_START + total size <= 200KB; abort with 413 on violation. |
| T-05-PATH | Tampering | upload target path | mitigate | Firmware computes /ss/saver_320_240_NNN.ss; client filename never used (no path traversal). |
| T-05-PRE | Tampering | preflight ?size= | mitigate | Parse as size_t with range check before LittleFS space comparison. |
| T-05-AUTH | Spoofing | all new endpoints | accept | No auth on local-LAN API — matches stock (documented LAN-trust model in webapi.cpp). |
| T-05-SC | Tampering | npm/pip/cargo installs | mitigate | Phase 5 installs ZERO new packages (RESEARCH Package Legitimacy Audit); slopcheck N/A. |
</threat_model>
