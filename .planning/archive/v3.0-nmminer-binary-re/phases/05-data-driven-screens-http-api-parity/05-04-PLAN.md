<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LittleFS .ss file -> nm_ss_decode | .ss bytes (possibly uploaded via 05-05) are untrusted input to the decoder. |
| LAN swarm peers -> nm_swarm list | Untrusted peer IPs cross into the swarm list. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-SS | Tampering | nm_ss_decode header | mitigate | Validate magic "SN" + width<=800 + (height-1)<=599 + width!=0 BEFORE allocating line buffer; stop on malformed LZSS back-ref (start<0). |
| T-05-SSRAM | DoS | decode buffers | mitigate | Fixed 640-byte line buffer + 1024-byte LZSS window allocated once; cap output at width*height pixels. |
| T-05-SWARM | DoS | swarm IP list | mitigate | Bounded dedup array (fixed cap); ignore overflow; short per-probe timeout to respect WDT. |
| T-05-NAV | Tampering/crash | screensaver vs page-switch | mitigate | s_nav_in_progress guard blocks screensaver activation mid lv_scr_load (Pitfall 6). |
</threat_model>
