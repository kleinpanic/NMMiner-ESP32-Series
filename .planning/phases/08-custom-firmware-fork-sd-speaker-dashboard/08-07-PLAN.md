<task type="auto">
  <name>Task 3: Push codebase and release tag to GitHub</name>
  <files>firmware/custom/NerdMiner-CYD-Custom/.git/refs/remotes/origin/</files>
  <action>
    Push the complete firmware codebase and release tag to the public GitHub fork. This is the final "ship" action.

    Steps:
    1. Change to repo: `cd firmware/custom/NerdMiner-CYD-Custom`
    2. Fetch any upstream changes (safety check): `git fetch origin 2>&1 | head -5`
       - If origin is empty (fresh repo), this should error gracefully (expected)
    3. Push all commits: `git push -u origin main` (or `master` if that is the default branch)
       - The `-u` flag sets up tracking for future pulls
    4. Push release tag: `git push origin v1.0.0-custom-cyd`
    5. Verify push succeeded: `git remote -v show origin` should show fetch and push URLs (both green/success)
    6. Confirm on GitHub web UI: visit https://github.com/kleinpanic/NerdMiner-CYD-Custom
       - Codebase visible, README displays, tag appears in Releases

    If push fails (auth error):
       - Check SSH key is loaded: `ssh-add -l | grep 88081AEE`
       - Or use HTTPS with personal access token: `git push https://username:token@github.com/...`
       - Check GitHub account settings: Settings → SSH and GPG keys (SSH key added)
  </action>
