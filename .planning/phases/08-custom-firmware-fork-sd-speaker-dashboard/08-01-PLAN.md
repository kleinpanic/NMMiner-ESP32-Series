<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local machine → GitHub (BitMaker-hub) | Cloning upstream source; verify HTTPS, no man-in-the-middle |
| Local .venv → PyPI | PlatformIO installation; pip install checks package signatures |
| Local filesystem → .git | Configuration and source code; .gitignore prevents secret leakage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering | Git clone of BitMaker-hub/NerdMiner_v2 | mitigate | Clone via HTTPS; verify remote URL in .git/config matches public BitMaker-hub URL (no typos in domain). Store git remote URL as constant in automation scripts. |
| T-08-02 | Information Disclosure | Secrets in .gitignore misses | mitigate | Add patterns for config.json, secrets.h, WiFi passwords, wallet keys, flash backups. Run pre-commit hook to warn on suspicious filenames (*.key, *secret*, *password*). |
| T-08-03 | Tampering | Compromised PlatformIO package | mitigate | PlatformIO installed from PyPI; pip checks package hashes. Pin major version (>=6.1.0, <7) in future to avoid breaking changes. |
| T-08-SC | Supply Chain | Upstream NerdMiner dependency | accept | MIT-licensed open-source; community-vetted. Upstream remote configured for future security updates. If upstream becomes compromised, our fork remains under our control. |

</threat_model>
