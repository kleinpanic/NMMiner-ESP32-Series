<objective>
Create the NVS-backed settings layer that the market, weather, screensaver, and API-parity
plans all read/write. Shared foundation (Wave 1) so the Wave-2 feature plans and the Wave-3
API plan key off identical field names and defaults.

Purpose: Stock API endpoints (`/api/setting/{market,weather,preference,...}`) and the data
screens must read the same persisted fields with stock-exact names/defaults (RESEARCH
§"Pattern 10" + §"HTTP API Parity — Endpoint Mapping"). Per D-52/D-53/D-54 the field set is
fixed by stock.

Output: `nm_settings.{h,cpp}` — a thin Preferences wrapper in a new `nm_stock` namespace
(distinct from the existing `nm_ui` LastPage namespace), plus the ScreenSaver-token->ms map.
</objective>
