<acceptable_evidence_set>
## RE-02 Acceptable-Evidence Set (resolves H3)

The verdict MUST cite **ANY TWO** of the following independent items. They are not ranked by which is "Signal 1/2" — any two distinct items qualify:

1. **DROM string family pattern** — presence/absence of `lv_img_decoder` / `LV_IMG_CF_*` (v8) vs `lv_image_decoder` / `LV_COLOR_FORMAT_*` (v9). Absence of the v9 family combined with presence of the v8 family is itself a positive signal.
2. **Decoder / render call-shape** — the decoder or image-render function's argument shape against the v8.3 vs v9 signatures (RESEARCH.md §Pattern 5), even when the function is an unnamed `FUN_xxxx`.
3. **`lv_img_dsc_t` / `lv_font_t` descriptor layout** — the 12-byte packed-bitfield v8 image header (no magic byte) vs the v9 descriptor layout; font-descriptor struct shape.
4. **Screen-constructor API signatures** — the `lv_obj_*` / `lv_label_*` call signatures inside a located screen constructor matching v8 vs v9 prototypes.
5. **Build-era / library version strings** — any embedded LVGL version string or build-era marker (Oct-2023 build predates LVGL 9.0 Jan-2024 — corroborating, not sole, evidence).

### Decision procedure when the two items DISAGREE
- Record BOTH items verbatim in SPEC.md (do not drop the dissenting one).
- ESCALATE: flag the disagreement loudly in 01-02-SUMMARY.md and add a third item from the set to break the tie.
- DEFAULT: if a tiebreaker cannot be obtained, prefer the **structurally stronger** signal — descriptor layout / call-shape (items 2-4, derived from binary structure) over string presence/absence (item 1) or build-era inference (item 5).
- Mark the resulting verdict's Confidence as `probable` (not `confirmed`) whenever the two items disagreed.

### Confidence labels (feed the SPEC.md Confidence column)
- `confirmed` — two items agree, at least one is structural (items 2-4).
- `probable` — two items agree but both are weak (item 1 + item 5), OR items disagreed and were resolved by the default rule.
- `tentative` — only one item is available; record it and flag RE-02 as not fully met until a second item is found.
</acceptable_evidence_set>
