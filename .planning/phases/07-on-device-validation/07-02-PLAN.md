<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Firmware config -> removable SD | Config values cross from firmware/NVS to a FAT card the user can remove and read on another machine. |
| SD config -> NVS | Operator-provided `/sd/config.json` may overwrite device settings if precedence is wrong. |
| USB serial/build host -> physical miner | Any backup/read_flash/write_flash/upload touches the live device and interrupts or overwrites the running miner. |
| Source tree -> git history | Docs and source may accidentally stage secrets, serial logs, or flash backup binaries. |
| Display build flags -> hardware panel | ILI9341/ST7789 mismatch can leave the next flash visually unusable if ignored. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Information Disclosure | `/sd/config.json` | mitigate | H1 removes firmware-written `WifiPW` from SD write-through; final notes confirm no secrets committed. |
| T-07-02-02 | Tampering | SD config import into NVS | mitigate | H1 makes NVS authoritative when valid; SD is fallback/import only when NVS has no usable SSID. |
| T-07-02-03 | Denial of Service | stale SD config causing Wi-Fi portal fallback | mitigate | H1 prevents stale SD from clobbering known-good NVS credentials; oversized/truncated SD config fails closed. |
| T-07-02-04 | Denial of Service | live device during repair | mitigate | This plan forbids read_flash/write_flash/upload/backup/verify_flash; current hardware status is tracked in the Phase 7 verification docs. |
| T-07-02-05 | Tampering | LVGL vs stock TFT setup rendering | mitigate | H2 keeps stock setup drawing from clobbering LVGL while routing config feedback through the LVGL page. |
| T-07-02-06 | Denial of Service | wrong panel driver or hidden board-target mismatch | mitigate | 07-REVIEW-FIX and 07-VALIDATION must record ILI9341/ST7789 evidence and keep the driver branch explicit before next flash. |
| T-07-02-07 | Information Disclosure | git history | mitigate | Verification rejects staged backup binaries and requires no secrets/serial logs in notes. |
| T-07-02-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install task exists; PlatformIO build uses the existing fork environment. |
