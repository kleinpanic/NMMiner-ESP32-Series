| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Information Disclosure | backups, recovered binaries, patched binaries | mitigate | Keep binary artifacts under gitignored paths; track only hashes, offsets, and derived analysis that contains no secrets or redistributable images |
| T-07-02 | Tampering | wrong binary target or public version drift | mitigate | Pin `v2.0.02` `esp32-2432s028r-st7789`; do not silently switch to `v2.0.03`; do not flash ILI9341 unless hardware is re-identified |

| T-07-SC | Tampering | new dependency/toolchain installs | accept | Current work uses existing local Python scripts and esptool/PlatformIO; no package install is needed for this plan |
