interactive. The boot button is already wired (OneButton in NerdMinerV2.ino.cpp) to the

re-pointed to nm_ui for the CYD env, NOT left calling the old path. Touch is polled from
the same non-mining loop that already pumps nm_uimanager_tick(), so the miner is never
starved. On-device tap confirmation is Phase 7; the gate here is BUILD SUCCESS + the
documented raw-Z diagnosis seam wired in.
